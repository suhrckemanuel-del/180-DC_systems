# V15 case-study gallery

`v15-case-study-gallery.html` is a self-contained prototype of only the gallery section shown on the V15 client page. It is not a replacement for the website and does not include a full site layout.

## Intended V15 placement

Replace the current `What a deliverable looks like` placeholder block on `for-clients.html`. Retain the existing V15 header, footer, fonts and general site styles; this component scopes its own styles to `#case-study-gallery` so it does not alter the rest of the page.

## Publish sequence

1. Keep a card private until its `PUBLIC-OK` record is complete.
2. Replace its anonymised draft copy with the approved case copy.
3. Build the target case-study page before enabling its `View case study` link.
4. Add cards four and five as a second row only after they clear their own approval gates.

The content source and safety rules are in `../../portfolio-workbench/v15-case-study-section.md`.
