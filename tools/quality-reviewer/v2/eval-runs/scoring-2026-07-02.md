Method note. Each review was generated by a fresh-context model instance that received
only the deployed prompt package (system prompt, rubric, contract, case-01 calibration
trio) and the filled team input template. The case file headers naming the failure mode
under test were stripped from the input. Gold labels were not read by the runner or by
the orchestrator until both outputs existed. Both outputs pass check-review-v2.js
including the verbatim-quote check. Scoring below was done by the orchestrator against
the gold labels after the runs, not by a separate fresh-context scorer (a session limit
blocked the independent scorer subagent). Treat the scores as one strict read, to be
re-checked when the scorer can run fresh.

the precision fraction but drive the restraint score down.

  programme analysis as fine and the drift as the problem. Flagging its sourcing as
  critical spends a critical on a recommendation that should not survive anyway.

  to replace), finding 5 (topic-label titles, true but not where a senior spends budget

  differs.

  explicitly says take the scope change to the client), no judgment of people.
