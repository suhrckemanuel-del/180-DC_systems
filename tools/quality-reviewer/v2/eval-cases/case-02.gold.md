# Case 02. Gold label

Human-written before the AI reviewed the case. Voice rules apply.

- **Case:** [case-02-problem-framing-drift.md](case-02-problem-framing-drift.md)
- **Artifact type:** draft deck.
- **Expected readiness:** Needs substantial revision (R1).
- **Expected readiness reason:** the deck is asked how to grow individual donations and
  ends by recommending a programme cut, so it answers a different problem than the one
  posed.

## Real top issues (ranked)

1. **Problem framing drift (blocking, rule 3).** Slide 2 states the question as growing
   individual giving. By slides 7 and 8 the deck recommends closing the mentoring scheme
   for programme efficiency. That is a different problem. Ceiling R1. Severity: high.
   Issue type: thinking.
2. **The donation question is never answered (blocking, rule 2, dimension 1).** The one
   genuinely on-topic finding (slide 4, donors would give more with impact updates) is
   dropped. The client's actual question gets no recommendation. Severity: high. Issue
   type: thinking.
3. **Analysis-to-recommendation link is on the wrong axis (major, dimension 5).** The
   programme performance analysis is sound but it answers efficiency, not fundraising.
   Severity: medium. Issue type: thinking.

## Acceptable AI feedback

- Names the drift explicitly and ties the opening question to the closing
  recommendation being about a different problem.
- Points out that the donor insight on slide 4 is the thread that answers the actual
  question and was dropped.
- Readiness R1 with the reason tied to answering the wrong problem.

## Unacceptable AI feedback

- Endorsing the mentoring cut as the recommendation. It may be a good idea, but it is
  not what the client asked and the reviewer must not bless a scope switch.
- Inventing donor data or a regular-giving benchmark.
- Judging the mentoring scheme's staff.

## False positives to avoid

- Flagging the programme analysis as weak. It is fine. The problem is that it answers
  the wrong question, not that it is poorly done.
- Flagging tone or slide design.

## False negatives to catch

- Missing the drift. This is the point of the case. A review that treats the mentoring
  recommendation as the answer has failed.
