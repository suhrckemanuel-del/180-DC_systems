# Reviewer handoff for a public portfolio case

Use this after the source pack is complete and a draft public case study exists. The draft must contain only the approved public wording and approved reconstructed exhibits. Do not attach the original client deliverable.

## Input record

| Field | Complete before review |
|---|---|
| Case label | `Client A` unless named publication approval exists |
| Artifact type | `final recommendation deck` or `implementation roadmap` |
| Draft format | 5-7 public case-study sections |
| Source pack | approved public claims, evidence references and exhibit permissions |
| Accountable lead | named person responsible for triage |
| Publication status | `not approved` until `PUBLIC-OK` is signed |

## Review brief

Ask the Quality Reviewer to assess only these questions:

1. Does the lead sentence make the client decision and the answer understandable?
2. Does each public claim have approved evidence, and does the draft distinguish fact, assumption, recommendation and verified outcome?
3. Does the storyline run from decision question through approach and insight to action?
4. Are recommendations specific enough to demonstrate consulting value without revealing sensitive operating information?
5. Does each reconstructed exhibit clarify a decision rather than decorate the page?
6. Would a prospective client understand how their own challenge might fit?

## Required Reviewer controls

- Use deep mode with the stated artifact type.
- Return exactly ten rubric dimensions in the standard order.
- Keep at most five findings and eight findings plus comments combined.
- Every finding must quote the public draft verbatim or be omitted.
- State the limits in `notAssessed`; do not invent client facts, outcomes or permissions.
- Treat the readiness result as diagnostic. It is not publication approval.
- The accountable lead accepts, turns into a question or rejects every kept finding.

## Exit criteria

- [ ] The revised public draft passed a quote check against its approved source pack.
- [ ] All retained factual claims and figures are on the claim register.
- [ ] The lead completed the triage record.
- [ ] `PUBLIC-OK` is signed by the named branch lead.
- [ ] The website card and page use only the approved public draft and exhibits.
