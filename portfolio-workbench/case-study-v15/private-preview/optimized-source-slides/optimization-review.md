# Reviewer-led slide optimisation

Status: private editorial review only. None of these exhibits is approved for publication.

## The benchmark

OAF page 31, “Bigger Picture Action Plan,” is the cleanest format in the selected set and should remain unchanged. It succeeds because one dominant three-step flow, three parallel content blocks and three explicit status bands can be understood before the body copy is read.

That format should guide hierarchy, not become a template imposed on every exhibit. A stakeholder matrix, an impact chain and a two-route recommendation each need different structures.
